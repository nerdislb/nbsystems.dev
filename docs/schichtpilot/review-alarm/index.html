Alarm foreground-service demonstration

Android 0.3.9-beta, version code 13. This continuous native screen recording uses a fresh Android 15 emulator and invented built-in demo data. No real user, roster, account or cloud sign-in is shown.

Open or download the MP4 directly. Android screenrecord produces a silent recording; no replacement alarm sound was added.

  1. Open Tools → Alarms & widget privacy. The real app shows that exact-alarm and notification permissions are available.
  2. Tap Test alarm in 15 seconds, leave the app and put the emulator screen to sleep.
  3. The scheduled alarm starts the real mediaPlayback foreground service, wakes the display and shows Test alarm with STOP ALARM.
  4. Tap STOP ALARM. The service and audio playback stop; return to the app.

The app uses a visible alarm notification and an explicit Stop action. Playback has a five-minute maximum. Delaying or interrupting a user-scheduled wake-up alarm could cause a missed shift. This is not a permanent background or cloud-sync service. This recording demonstrates foreground-service use, not a claim of reliability on every physical device or an application for default full-screen permission.
